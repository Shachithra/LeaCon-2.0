# Contact portraits

Drop the two Event Manager portraits here with these exact names:

| File       | Used for                          |
| ---------- | --------------------------------- |
| `em1.jpg`  | Shachithra Senanayake (Contact EM1) |
| `em2.jpg`  | Isula Illeperuma (Contact EM2)    |

Guidance:

- **Crop:** 4:5 portrait (e.g. 800 × 1000 px) — the card uses `aspect-ratio: 4 / 5`.
- **Focus:** head and shoulders, centred, some headroom.
- **Format:** `.jpg` (or `.png`/`.webp` — update the `src` in `index.html` if you change the extension).
- **Weight:** keep each file under ~300 KB.

Until a file exists, the card falls back to the indigo `EM1` / `EM2` monogram automatically.
